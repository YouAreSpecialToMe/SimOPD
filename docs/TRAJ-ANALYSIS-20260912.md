### 4.3 结论

1. **这对师生结构上产生不了 Mode B。**「学生学会提前发终止符」要求教师**在普通位置**给终止符不低的质量,
   采样到它才能拿正优势。实测:正文中位 1e-13、超过 0.5 的位置在 200 步之前是 **0**。
   这个通道是关着的 —— 与我们 51 个 run 里从没出现过 Mode B 一致(`AUDIT-20260911-setup.md` §10.3)。
2. **只有 Mode A 那一侧的压力。**原始采样列上,学生停止位的 `dl`(stu−tch)= +26…+69(§1),
   即停止被重罚;而全序列任何地方都没有能抵消它的正信号。**单向压力,没有反向压力。**
3. **晚期出现的热点是「写完了还在写」。**`vanilla_corr` 的热点只在 200 步后出现,且首个热点在第 8372 位
   (均长 8711)—— 也就是**结尾已经写好、又续了 192–474 个 token**。这是 `MECHANISMS.md` M-I 记的
   「多出来的 token 97.3% 是教师收尾模板的复读」在修正载体上的小剂量版本,与 §1 的 `rep4`≈0.54 对得上。
4. **对 Demystifying 的 Mode B**:判据的另一半仍然要在**他们的 chat 线自训 GRPO 教师**上量。
   我们这半边是干净的阴性对照 —— 现货 Instruct 教师不给正文终止符质量。若他们的教师给,Mode B 的镜像解释成立;
   若也不给,就只剩他们自己的 Eq.6 解释(而 Eq.6 又依赖 seq-mean 聚合,见 §10.5)。

**教得最狠的是什么。**`r>3` 的 5,730 个 token,前十四名:空格、` the`、` $`、`.\n\n`、`,`、`But`、
` **`、` a`、`So`、` is`、` and`、` \`、` in`、`1`。替换对(学生写 X → 教师想要 Y)里大量成对对冲:

```

","  → ".\n\n" 22 次  ".\n\n" → "," 21 次
"2"  → "1" 15 次      "1" → "2" 12 次
```

**最强的信号里有相当一部分净效应为零** —— 在两个同样合理的写法之间来回拉扯。

## 9 这一轮 29 条臂的载体分三类(09-14)

## 10 d3 实现复核(09-14)

内核(`topk_losses.py:1127`)与论文/官方码结构一致:`s = D̃ · C̃`,兼容性 = 教师质量落在学生 top-16,
归一用官方默认 `batch_quantile`(Q05/Q95),K=16 字面引进。**但三处限定必须进判决:**

**一、预算 5% 是摘要档,论文主表是 10%。**我们跑的是更苛刻的一档(175 步 0.484)。
建议补 `d3@10%`(零代码,`SIMOPD_D_RETENTION=0.1`,≈100 GPU·h)。

**二、兼容性因子退化。**实测 `teach_compatibility` 0.91→0.97,而其上限(教师 top-k 总质量)是 0.998 ——
教师质量几乎全部落在学生 top-16 内,该因子近乎常数,**选择实际由 disagreement 主导**。
这正是论文自己警告的失效模式("raw disagreement mixes support-aligned corrections with off-support
mismatch"),而 C 因子存在的目的就是滤掉不可学的分歧。在这对师生上支撑重合度 0.98,
**没有多少不可学分歧可滤,C 因子无事可做**。TA-OPD 用的是 GRPO 思考型教师 + DAPO,分歧结构应宽得多。

**三、归一化种群漂移**(登记在案):16k 响应饱和打包上限后一个微批只装一条序列,
`batch_quantile` 从跨序列漂成事实上的逐序列。

**判决措辞:实现忠实,但它在这对师生上测不到它想测的东西。**
