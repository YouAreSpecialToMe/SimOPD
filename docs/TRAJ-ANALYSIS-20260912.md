## 0 先钉两个约定(读这批数之前必须知道,我第一遍就读反了)

1. **`dl = stu_lp − tch_lp`,取的是采样列**(`traj_dump.py:326`)。即
   `dl = log p_θ(y_t) − log q_T(y_t)`,**与损失侧/审计文档里 Δℓ = log q_T − log p_θ 的约定符号相反**。
   而且它是 **raw、未经事件级修正的量**(F6 面板约定:面板记原始 k1,损失才走 termfix)。
   所以在修正载体上,这一列**照样**显示终止符错位 —— 那不是 bug,是这列的设计目的。
2. **`p_last_151643` / `p_last_151645` 是教师的概率**(`= exp(tch_lp_<sid>[-1])`,`traj_dump.py:334`),
   不是学生的。读作「在学生停下来的那个位置,教师给 eot / im_end 各多少概率」。

**三条读数:**

1. **错位本身在原始信号里照旧,而且随训练变深。**`dl_last` 从 +26 涨到 +69 —— 教师在学生停下来的那个 token 上
   给 e^−26 到 e^−69。这与 08-20 的 N0 审计 T4(相反符号下 step 10 约 −16~−18、step 100 约 −50~−64)一致,
   是同一现象在新集群、新栈上的复现。**修正改的是损失读哪一列,不是让错位消失。**
2. **教师"想在这里结束"的意愿被训练侵蚀。**教师在学生停止位上给 im_end 的概率 **0.624@25 → 0.088@100 → 0.28@250**,
   教师 top-1 是终止符的比例 **66.4% → 8.6% → 30.5%**。即:开头学生停在教师也想停的地方,中段开始
   **学生停在教师还想继续写的地方**。事件级修正仍然在发放信号(损失读 q_T(E_T)),但它读到的那个量在变小。
   这是"修正为什么只是稳住而不是治好"的一个可测量的机理候选,`n2` 那条校准通道正是冲这个去的。
3. **健康 ≠ 不复读。**`rep4` 在 0.31@25 冲到 0.71@50,之后**稳在 0.53–0.54**。载体是"稳定但高度复读",
   长度停在 ~9.2k、截断 4–12%。论文里说"修好了"要带这个限定。

### 4.3 结论

1. **这对师生结构上产生不了 Mode B。**「学生学会提前发终止符」要求教师**在普通位置**给终止符不低的质量,
   采样到它才能拿正优势。实测:正文中位 1e-13、超过 0.5 的位置在 200 步之前是 **0**。
   这个通道是关着的 —— 与我们 51 个 run 里从没出现过 Mode B 一致(`AUDIT-20260911-setup.md` §10.3)。
2. **只有 Mode A 那一侧的压力。**原始采样列上,学生停止位的 `dl`(stu−tch)= +26…+69(§1),
   即停止被重罚;而全序列任何地方都没有能抵消它的正信号。**单向压力,没有反向压力。**
3. **晚期出现的热点是「写完了还在写」。**`vanilla_corr` 的热点只在 200 步后出现,且首个热点在第 8372 位
   (均长 8711)—— 也就是**结尾已经写好、又续了 192–474 个 token**。这是 `MECHANISMS.md` M-I 记的
   「多出来的 token 97.3% 是教师收尾模板的复读」在修正载体上的小剂量版本,与 §1 的 `rep4`≈0.54 对得上。
4. **对 Demystifying 的 Mode B**:判据的另一半仍然要在**他们的 chat 线自训 GRPO 教师**上量。
   我们这半边是干净的阴性对照 —— 现货 Instruct 教师不给正文终止符质量。若他们的教师给,Mode B 的镜像解释成立;
   若也不给,就只剩他们自己的 Eq.6 解释(而 Eq.6 又依赖 seq-mean 聚合,见 §10.5)。
