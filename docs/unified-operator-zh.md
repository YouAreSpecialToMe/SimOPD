## 1. 核心立场:OPD 是一个更新算子,不是一个标量损失

对 prompt `x ~ 𝒟`,冻结的行为策略生成 rollout `y ~ μ_θ̄(·|x)`;记访问状态
`s_t = (x, y_<t)`,学生分布 `p_t^θ = π_θ(·|s_t)`,老师分布 `p_t^T = π_T(·|s_t)`。
更新场写成一条复合表达式:

```
         E_{x,y} [ w(y) · (1/Σ_t m_t) · Σ_t  m_t ·
g(θ)  =  ────────  ℛ( Φ( 𝒬[ D( S(N_ν(Res_Ω p_t^θ)),  S(N_ν(Res_Ω p_t^T)) ) ] ) ) ]
         E_{x,y} [ w(y) ]
```

研究对象是这个**场**本身:一个 OPD「方法」= 在这条链上的一组耦合设计选择;
`configs/arms.yaml` 里的每个臂 = 其中一次受控的单坐标移动。

## 2. 四宏坐标:整个设计空间的一句话总结

```
g(θ) = g(θ; Γ, 𝒜, 𝒞, 𝒰)

Γ = (μ, w, m)      教哪里、教什么
𝒜 = (Ω, ν, S)      能看到什么信息
𝒞 = (D, 𝒬)         师生怎么比
𝒰 = (Φ, ℛ)         比完怎么变成参数更新
```

| 宏 | 子坐标 | 含义 | 名册取值举例 |
|---|---|---|---|
| **Γ** | `μ` | 访问哪些状态(λ 混合、T_max、n) | on-policy / GKD λ / h5 的 T_max=100 |
| | `w(y)` | 整条轨迹级选择 | 全收 / 只收 pass / 只收 fail / 配额 K / 似然过滤 |
| | `m_t` | token 级监督分配(预算 ρ × 选择规则 P) | 位置窗口(h 族)/ 随机散布 / 熵与分歧判据(d 族) |
| **𝒜** | `Res_Ω` | 词表支撑限制 | 采样点 {y_t} / top-k / 分位预算 / 交集 / π-tail |
| | `ν` | 支撑/尾质量的表示 | raw / renorm / 尾桶 |
| | `S` | 保留老师信息的分辨率 | 值 / z 形状 / 序 / 集合隶属 |
| **𝒞** | `D` | 差异几何 | RKL / FKL / skew / JSD / 幂比较子 |
| | `𝒬` | 有限求值方式 | 精确支撑求和 / 采样点 Monte-Carlo(student-MC) |
| **𝒰** | `Φ` | 有效信号整形 | id / soft-log / clip / 单侧 clip / tanh |
| | `ℛ` | 梯度实现 | score-function(PG)/ 直接微分 / k2 势函数 |

两条诚实条款:

1. **四宏不可独立设定**(分层积空间):动 S 会机械拖动 Ω/ν/𝒬/ℛ——即一次 𝒜 移动
   会强制 𝒞/𝒰 内的 carrier 选择。实验纪律是逐轴 carrier(每轴只动一个科学坐标,
   机械必需的坐标轴内钉死),不是自由四因子网格。
2. **设计宏 ≠ 机理坐标**:两个名义不同的方法若诱导同一更新几何,机理上等价;
   同一名义目标的两种实现若 ℛ 不同,行为可以天差地别。两个方向**都已有实测**:
   b5↔vanilla(场在 ratio=1 处重合,锁步只差 3 步)与 c1↔c1_direct(同一求值
   标量、只换 ℛ:+0.221 val@25、种子散布 47×、稳定性翻转)。

## 3. vanilla:整个空间的原点

```
Γ₀ = (π_θ̄, 1, 1)          纯 on-policy;每条轨迹;每个 token
𝒜₀ = ({y_t}, raw, id)      采样点支撑;原始质量;全值分辨率
𝒞₀ = (RKL, student-MC)     反向 KL,在采样 token 处求值
𝒰₀ = (id, score-function)  信号不整形,PG 实现
```

由此 `r_t = log p_t^θ(y_t) − log p_t^T(y_t)`,`g_t = r_t·∇_θ log π_θ(y_t|s_t)`。
在固定访问状态处成立恒等式

```
E_{y_t ~ p_t^θ}[ g_t ] = ∇_θ KL(p_t^θ ‖ p_t^T)
```

(+1 项因全支撑上 Σ∇p=0 而消;截断支撑上须 renorm 或 detach 才能保住——名册
内核全部满足)。**vanilla 是四样东西恰好对齐的特殊点**:on-policy 采样、反向 KL
几何、采样 log-ratio、score-function 实现。其余每个臂都是对这条链的一次受控
打断;论文读的就是每次打断对更新场和训练动力学的影响。

## 4. 实验纲领:动设计坐标,量机理坐标

扰动上述设计坐标之后,测量的是**机理坐标**:支撑质量、有效样本数、被放行的
信号尾部、熵、序列长度、截断率、锁帽时间(time-to-lock)。由此:

- **剂量线**:固定 carrier 沿一个设计坐标取截面(λ 线、β 阶梯、位置线);
- **screening-off 检验**:活在涌现机理坐标上(如 M[g] = 更新场的有效信号界);
- **效应分解**:走 (𝒬×ℛ) 对角外配对(c1 三角把速度/方差/稳定性拆到 ℛ 与 ν);
- **可组合性**:逐坐标最优是否能拼成配方——框架最后一条可证伪预言。

## 校勘记(评审稿 → v2 正文的两处修正)

1. **w 的归一化**:评审稿框式归一了 m 未归一 w;正文改为 `E[w·(…)]/E[w]`,
   两个选择权重对称(即代码实际发货的**双重条件均值**)。差别不是形式:G 轴
   pass 率 0.5–2% 时 `E[w·L]` 与 `E[L|w=1]` 差 50–200×,g1_quota 的方差干预
   读法建立在条件均值估计量上。
2. **M(𝒰) → M[g]**:涌现的幅度界不是 (Φ,ℛ) 的函数——b1(skew)与 f3(幂比较)
   的界从 𝒞 诱导。改记 M[g] 后,幅度统一假设更锋利:动力学 factor through
   M[g],**screening off 界由哪个宏诱导**;f2_clip2.3(𝒰 诱导、钉在 b1 的 𝒞
   诱导值 2.303)即校准干预,预注册锁步 ≈ 247。

另:`Q_Ω` 改名 `Res_Ω`(拆掉与求值算子 𝒬 的视觉撞车);符号约定为 g 是 KL
梯度、更新取 `θ ← θ − ηg`,verl 代码侧 advantage = −r,全部整形为奇函数故两套
约定可交换;J 轴的 `L_task + c·L_OPD` 耦合、初始化 θ₀、τ=1、n=1 在算子**之外**,
钉死并披露。
