# 臂表复审(2026-09-01):修正 eos 前后对照,哪些臂该删、该改、该加

**数据**:legacy 波(载体 `k1_rec`,29 臂 × 3 种子,4700 格)与修正波(单种子,51 run 动态、
339 格)全部在 `docs/data/`;判读台 `docs/collapse-cure.html`;数字由
`scripts/analysis/collapse_status.py` 与 `make_cure_page.py` 重算。
**判据**:离线 composite 只在**同契约**(`stop_set=off`)内做**同步差**;动态看晚期窗口
(最后 25 步的长度 / 截断率 / 熵);k=8 之后"药效归零"那档 ±0.01 **只在曲线层面读**。

## 0 先把"修正"拆开——它不是一个旋钮,是三种

| 修法 | 机制 | 用在哪 |
|---|---|---|
| **`k1_termfix`**(N0 载体) | 只在学生的停止位把 token 级 `log q_T(eot) − log p_θ(eot)` 换成**事件级**读数(教师终止质量 Σ_{E_T} q vs 学生停止质量);其余位置原封不动,无系数、无新通道 | `vanilla_corr`、所有 `_n0` |
| **gather-only**(精确终止符列进支撑,不折叠) | `TOPK=32+2`,两个终止符以精确 q 作为普通支撑列进内核 | `c4_carrier` / `c4_rep` / `c4_hq` / `c4_state`、`c5_union_*` |
| **`TERM_EVENT=1`** | Path 1:采样列换事件级值;**Path 2:把教师支撑的终止符坐标折叠到学生停止 id 上再重排** | 所有 `*_corr`(18 条)、`n2_corr` |

三种在数据上**不等价**。单变量对照 `c4_carrier`(gather-only)vs `c4_pi_tail_budget_corr`
(同 TOPK 34、同 PG=False、同 gather,**只多 `TERM_EVENT=1`**):160–187 步窗口长度
8,901 vs **11,133**,截断 0.020 vs **0.334**,后者被判"危险"。对**本身就消费精确终止符列**
的内核,Path 2 的折叠是画蛇添足,而且有害。而 f/g/d1/h3 这些 k1 族的 `_corr`(TE=1)全部
健康且 ≡ vanilla_corr——TE 对**采样式 k1 内核**是对的修法。结论:**TE 是 k1 族的修法,
不是 top-k 族的**;top-k 族里原生读终止符列的内核应走 gather-only。

## 4 这次复审改掉的三条原则

1. **"修正 = 同一臂 + 同一个旗标"不再成立。** 三种修法在 c4 上给出相反的结果,主表必须
   标注每条臂用的是哪一种,`vanilla_te` 那格是把它们钉在一起的唯一办法。
2. **legacy 排名不再作为"哪条臂有用"的证据。** 它量的是抗塌缩;论文里 legacy 表的读法改为
   "哪些臂在坏载体上不塌"。
3. **动态可以先于评测下 null 判决。** 16 条删出重训的臂,判据是晚期长度/截断与 vanilla_corr
   ±3% 且无一条曲线分岔;评测只用来收口有信号的臂。这是 k=8 之后必须的纪律,不然评测
   预算永远追不上。
