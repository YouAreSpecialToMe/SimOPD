## R-H1 深度剂量线(h5/h7/h8 + vanilla 端点)

- **问题**:固定 rollout 深度砍到全窗的 0.6%/3%/12.5% 时,离线套件分数保留
  多少?ESR/TOPD 的"浅即够"论断在本协议(16k 窗、4B→1.7B)是否成立?
- **预测 D-cheap**:剂量线平坦——h8(12.5%)基本持平 vanilla,h7 轻微损失,
  h5 已知点落在线上;TOPD 的 ~10% 论断被夹逼证实。
- **预测 D-deep**:分数随深度单调且实质下降(深尾 rollout 是承重的),浅帽
  的效率收益以质量换来。
- **裁决**:离线套件(5 基准,战役同标准)对 250 步终档;主图为分数 vs 实际
  生成 token(侧带 h_gen_tokens 积分)的效率前沿,并报中间存档的前沿包络。

## R-H2 时间表 vs 固定深度(h6 对 h5/h7/h8 剂量线)

- **问题**:同为省 token,递进帽(128→16384)是否优于固定帽?(A 轴 R2 的
  深度轴镜像)
- **预测 S**:h6 终局显著优于与其**生成 token 总量相近**的固定臂(前期浅帽
  迭代快、后期全深收尾,两全);
- **预测 C**:前沿上 h6 与固定臂重合——token 总量是充分统计量,时间表次要。
- **措辞约束**:比较一律在效率前沿上按实际生成 token 对齐,不按名义帽。

## R-H3 自适应 vs 盲时间表(h9 对 h6 与固定臂)

- **问题**:证据驱动的预算(教师失线可靠长度)是否优于与其 token 总量相近的
  盲时间表?
- **预测 A**:h9 在前沿上占优——预算贴着"教师还教得动"的区域走,不为死重
  尾部付费也不盲目饿短;
- **预测 N**:不优于简单时间表(Prune 架构在此协议的增益边际),或早训预算
  塌得过狠(彩排已见 ~350 量级)伤及质量,h9 落在前沿之下。
- **已见披露**:彩排预算轨迹利于"控制器工作"的机制判断,但对 A/N 双方的
  质量裁决无信息量(3 步无质量读数)。
- **裁决**:同 R-H1 前沿;辅助:h9_budget 全程轨迹与 val 曲线的对照(预算
  回升/继续下探的形态本身是 ESR 教师衰减故事的时间演化测量)。

## R-H4 任务覆盖面(h10 对 vanilla)

- **问题**:砍半任务集(同步数、同深度、子集多刷 ~2 倍 epoch)后,离线套件
  是否受损?
- **预测 C-free**:h10 ≈ vanilla——任务覆盖面不是 token 花销的承重墙,
  聪明的任务跳过有接近 2x 的免费效率空间;
- **预测 C-load**:h10 < vanilla——覆盖面承重,任务维度的省法须比随机砍半
  更聪明(通往 PACED 式加权的论据)。
- **裁决**:离线套件终档 + 曲线;h10 的每步 token 与 vanilla 相同,此条目
  裁决的是"可跳过性"而非直接省费。

## 度量法令(全轴共用)

名义帽/名义时间表;质量 = 战役同标准离线套件;头图 = 质量-token 前沿,
GPU 时长为副图。h9 若进任何"等预算"比较,预算轴同样取实测积分。
